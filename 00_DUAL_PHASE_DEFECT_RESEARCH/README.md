# 双対位相欠損研究

## 位置づけ

本区分は、`00_4_MINUS_PI_RESEARCH/` の直後、総論・各論の前に置く独立研究区分である。

4-π研究が正方形の面積欠損と動径–法線角エネルギーの一致を扱うのに対し、本研究は、原点を内部に含む平面凸体 `K` と極体 `K°` の間の**回転相似自己極性からの連続的なずれ**を測る。

中心汎関数は

\[
E_K(\alpha)
=
\min_{s\in\mathbb R}
\frac1{2\pi}
\int_0^{2\pi}
\left[
\log h_K(\theta)+\log\rho_K(\theta-\alpha)-s
\right]^2d\theta
\]

である。

\[
E_t''\!\left(\frac\pi2\right)
=-2+\frac{4\log2}{\pi}\left(t+t^{-1}\right)
\]

- 臨界アスペクト比

\[
t_c=
\frac{\pi+\sqrt{\pi^2-16(\log2)^2}}{4\log2}
=1.6659061655162109\ldots
\]

- 四階微分の閉形式と `E_{t_c}^{(4)}(π/2)>0`
