# 追補｜Codex の要約に書かれた数値との照合

2026-11-20 ／ 扱い：DIAGNOSTIC_ONLY / NOT_EVIDENCE ／ 非区間（倍精度浮動小数点）

ユーザーが貼り付けた Codex の要約の数値を、このディレクトリの独立な実装で計算し直した。Codex の報告書、コード、区間計算の出力そのものは読めていない。照合したのは要約の本文に書かれた数値だけである。
コードは `code/crosscheck_codex.py`、出力は `out/crosscheck_codex.json` である。本体の ZIP と `SHA256SUMS.txt` は変えていない。

| 項目 | Codex の要約 | この実装（非区間） | 判定 |
|---|---|---|---|
| t = 3 の停留円の半径 | 13/16 < r* < 27/32 | r₀ = 0.823938265 | 区間の中にある |
| 角度依存の一次項の係数 c（半径帯の全体） | −0.241 < c < −0.152 | B(r) = ½(T₂₂ − T₁₁) は帯の両端で −0.1907 と −0.2024、r₀ で −0.194961 | 区間の中にある。c と B は同じ正規化と読める |
| Z₁ と ∂₂ の交点 | (s, t) ≈ (1.56697, 2.29659) | (1.566969, 2.296586) | 書かれた桁まで一致 |
| (s, t) = (1.25, 32) での E₂/q₂ − E₁/q₁ の符号 | 境界の近くで逆転する。そこで E₃/q₃ > 0 | 20 点のうち 2 点で負（最小 −0.0017）。どちらも \|q\| ≥ 0.99、q₃ ≠ 0。E₃/q₃ は 20 点すべてで 0.41 以上 | 一致 |

補足は次のとおりである。

- 係数の正規化：この実装では、停留円の上の簡約関数を Φ_s(φ) = Φ_1 + (s−1)(定数 + B cos 2φ) + O((s−1)²) と書く。B = ½(∂E/∂ℓ₂ − ∂E/∂ℓ₁) = ½(T₂₂ − T₁₁) である（REPORT.md の命題 5 では τ = −2B）。2B なら Codex の区間から外れるので、c = B と判断した。Codex の定義そのものは確認していない。
- (1.25, 32) で符号が負になった 2 点は、どちらも面 q₃ = 0 の外（e₃ から 30° の方向）にある。面 q₃ = 0 の上の 4 点では正だった。4 点だけなので、この形で面の上の不等式が成り立つとは言えない。
- 主格子の形の数（195 形、168 形の内訳）は、格子が違うので照合していない。
