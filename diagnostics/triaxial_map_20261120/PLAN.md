# 数値計画（実行前に固定）｜三軸楕円体の族：停留点の地図

2026-11-20 ／ 扱い：DIAGNOSTIC_ONLY / NOT_EVIDENCE ／ 非区間（倍精度浮動小数点）

この文書は本実行（Run A〜E）の前に固定する。固定時の SHA-256 は `PLAN.sha256` に記録する。
固定後に計画から外れた点は、報告書の「計画からの逸脱」に書く。

## 0. 固定前に済ませたパイロット（結果は計画の入力として使った）

- 式の検査 `code/check_formulas.py`：物理的な定義との一致、勾配と Hessian の差分との一致、境界トレースの内側からの極限。
- 求積の収束表（形 5 種 × 基点 8 種）。
- 辺の 4 臨界値の再現：λ_c^ob、λ_∂^ob、λ_b^pro、λ_c^pro。
- 粗い 10×13 格子での h₁,h₂,h₃ と極点トレース E_i(e_i) の符号の下見（格子の範囲を決めるため）。

## 1. 記法

- L = diag(1, s, st)、s,t ≥ 1。基点 q は参照球、軸は e₁（最短）、e₂（中間）、e₃（最長）。
- 出力は E、E_i、E_ij（核 `code/triax_kernel.c` の冒頭の式）。
- 求積：log-chord 座標（τ に Gauss–Legendre、φ に台形）。節点数 n×n は軸比 a = st で決める。
  a≤2: 96、≤3.5: 128、≤6: 192、≤12: 256、≤20: 384、≤32: 512、それ以上: 768。

## 2. 本実行

### Run A：主格子の census
- 格子：s_i = 4^(i/32)（i=0..32）、t_j = 8^(j/40)（j=0..40）。33×41 = 1353 個の形。辺 s=1、t=1 を含む。
- 各形で次を求める。
  1. 中心：h₁,h₂,h₃。
  2. 軸：各軸 e_i の上で g_i(r)=E_i(r e_i) を r_j = sin(π j/128)（j=0..64）で評価し、符号変化を Brent 法で詰める。
     r_1 より内側の根は、h_i と g_i(r_1) の符号の不一致で検出する。根での Hessian（対角）を記録する。
  3. 座標面：各面の四分円で r∈{sin(π j/40)}（j=1..19）× 角 9 点の格子から、Newton の 1 歩が 0.35 以内に収まる点を種にして
     面内 2 次元 Newton を回す。
  4. 一般の位置：第一八分円で r 12 点 × θ 7 点 × φ 7 点（座標面と軸を除く内部の点）から、同じ規則で 3 次元 Newton を回す。
  5. 境界：単位球面の第一八分円で、制限 E|S² の臨界点（接方向の勾配トレースの零点）を、軸の 3 点、大円弧 3 本（33 点の走査）、
     開いた八分円（13×13 格子＋2 変数の求根）で求め、各点で法線成分 N = ∇E·q と接方向の Hessian（差分）の指数を記録する。
  6. 整合の検査（Morse の境界つき指数公式）：Σ_内部 (−1)^指数 ＋ Σ_{境界, N<0} (−1)^{接方向の指数} ＝ 1。
     対称性の重複度（軸 2、面 4、一般 8）を掛けて数える。
- 収束した停留点は、|∇E| < 1e-9、|q| < 1 を条件とし、第一八分円に写して 1e-6 で重複を除く。
- 辺（s=1 または t=1）では回転対称のため停留円が退化する。辺の上では軸の census と中心だけを採用し、円は軸の根として数える。

### Run B：分岐曲線の追跡（格子と独立）
- 中心の零曲線 h_i(s,t)=0、極点トレースの零曲線 ∂_i：E_i(e_i)=0 を、s（または t）を固定した Brent 法で追う。
  求積は n と 1.5n の一致（1e-9）を確かめて決める。
- Run A が軸の折り返し、横断方向の退化、面内の枝を見つけた場合は、その曲線も同じ方法で追う。
- 辺の上の 4 臨界値に連続につながることを、辺への外挿ではなく辺の上での直接計算と比べて確かめる。

### Run C：辺の近くの分裂
- 扁長辺：s = 1+δ（δ = 1e-3, 3e-3, 1e-2, 3e-2）で、e₁ 軸と e₂ 軸の枝の位置、指数、一次の分裂係数
  B(t) = ½(∂/∂ℓ₂ − ∂/∂ℓ₁)E（停留円上の点 (r₀(t),0,0) で）を求め、分裂の正規形 A + B cos 2φ と比べる。
- 扁平辺：t = 1+δ で e₁ 軸の対が残ること、赤道方向の固有値の分裂を確かめる。

### Run D：球の近く
- 球での動径プロファイル g(r) と閉じた式の比較。s,t ≤ 1.25 の 9×9 格子で census を取り、中心以外の停留点がないことを確かめる。

### Run E：無限遠の見通し
- h₂=0 と ∂₂ の曲線を s ≤ 64 まで、h₁=0 に関係する量を t ≤ 64 まで追う。高い n で収束を確かめる。
- 扁平な極限 s→∞ の候補となる 2 次元の極限汎関数を導き、曲線の極限値と比べる。

## 3. 採否の規則（実行前に固定）

- 数値は「数値の結果」として報告する。証明済みの事実とは分けて書く。
- 求積の誤差は、抽出した点で n を 1.5 倍にした再計算との差で見積もる。差が 1e-6 を超えた形は表で印を付ける。
- 整合の検査（Run A の 6）が合わない形は、隠さず一覧にする。種の格子を細かくして再計算し、その結果も併記する。
- 乱数は使わない（式の検査の乱数の種は 20261120 に固定済み）。
