# basepoint ―― 基点幾何の実験台

汎関数を**レンズ**として固定し、**基点**を動かして対象の停留構造を抽出し、
その構造が**形状の変形**に沿ってどう変わるかを追うための道具。

指紋 = ラベル付き停留集合（成分次元・軌道サイズ・法方向モース指数・核次元・等方型）。
本パッケージは指紋を計算し、形状空間上でその変化を地図にする。

> **証拠クラス: DIAGNOSTIC_ONLY / NOT_BINDING**
>
> 返る数値はすべて倍精度の探索値であり、区間包絡でも認証でもない。
> 認証は producer/checker の分離、clean-room 実行、SHA 固定、独立監査を要し、
> 本パッケージはそれを行わない（`Quantity.certified()` は常に `False`）。
> ここでの役割は、**何を認証すべきかを見つけること**である。

## 層

| 層 | モジュール | 役割 |
| --- | --- | --- |
| 幾何 | `geometry`, `quadrature` | 対象のパラメータ表示、法線、面積要素 |
| レンズ | `lens` | 角度核 `h(γ)` と重み `w`。**差し替え可能** |
| 汎関数 | `functional` | `E(p)` と基点についての微分、中心係数 |
| 停留構造 | `stationary` | 軸上の根、子午面 census、Newton 精密化 |
| ラベル | `labels` | 軌道の同定と指紋の付与 |
| 族 | `family` | 形状空間（体積一定回転楕円体 / 三軸楕円体） |
| 走査 | `scan` | 族に沿った退化点、分岐集合、枝の追跡、境界進入 |
| 診断 | `diagnostics` | 格子収束と**対称性残差**（下記） |

## 使い方

```python
from basepoint import ConeVolumeAngleLens, ConstantVolumeSpheroid, Functional

fam, lens = ConstantVolumeSpheroid(), ConeVolumeAngleLens()
F = Functional(fam.body(4.7243834), lens)
F.center_coefficients().value        # 中心 Hessian の主係数 Q_i

from basepoint.scan import degeneracy_parameter
degeneracy_parameter(fam, lens, (4.0, 5.5), component=0).value   # 臨界軸比
```

```bash
python3 -m unittest discover -s tests -t .   # control（18件）
python3 examples/01_spheroid_family.py       # 族に沿った大域構造
python3 examples/02_shape_plane.py           # 形状平面の分岐集合
python3 examples/03_lens_swap.py             # レンズを替える実験
```

依存は numpy のみ。

## 精度は結果自身から測る

軸の置換 S₃ で移り合う形状点は、同じ指紋を持たねばならない。
`diagnostics.s3_residual` はその不一致を測る ―― **外部の参照値を要しない精度の代理**である。

| 軸比 | S₃ 残差（Grid 96×96、錐体積レンズ） |
| ---: | ---: |
| 2.0 | 3.5e-12 |
| 4.72 | 8.3e-10 |
| 8.0 | 2.0e-05 |
| 12.0 | 1.8e-03 |
| 25.0 | 1.2e-01 |

この検査は実際に誤りを捕まえた。面積重みレンズで軸比 25 付近に「軸方向の退化」が
見えたが、S₃ 残差が 0.15 と大きく、格子を細かくすると符号が反転して消えた。
**構造ではなく求積誤差だった。** `diagnostics.converged_value` は収束しない量に対して
値を返さず、`scan.bisect` は符号変化のない区間で根を捏造せず例外を送出する。

## レンズは実験変数

`h(γ)` は `γ=1`（法線入射）で解析的でなければならない。対称体では中心が常に停留点で、
その近傍の展開がこの性質に依存するためである。`arccos(γ)^k` は **k が偶数のときのみ**
`(1−γ)` について解析的で、奇数のときは `√(1−γ)` 特異を持つ。
`Lens.smooth_at_normal_incidence` がこれを保持し、非解析なレンズでの中心係数計算は警告する。

冪 4 では `α = O(|p|)` ゆえ `h = O(|p|⁴)` となり、**球で `Q = 0` が厳密**に成り立つ。
同じ族でもレンズを替えると指紋の質が変わる、という最も単純な例である。

## しないこと

- 認証・区間包絡・producer/checker 分離（別のリポジトリの役割）
- 非存在の証明。有限標本で検出されなかったことは何も証明しない
- 停留集合の大域的完全列挙
