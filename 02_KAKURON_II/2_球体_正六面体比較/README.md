## 分類理由

球体の完全な O(3) 等方性と正六面体の有限 O_h 対称性を比較し、中心の等方 Hessian、四次異方性、中心–頂点境界値恒等式を横断的に扱うため、各論 II に比較研究の索引を置く。

## 主要内容

- 球体中心 `D^2E_B(0)=(4/3)I_3`
- 球体中心は唯一の停留点・唯一の大域最小
- 正六面体中心の等方局所最小
- 正六面体における最初の異方性次数4
- 正六面体中心値と頂点境界値の厳密恒等式

単体分類の本体は、球体を `各論 I/1-1`、正六面体を `各論 I/2-2` に置く。
