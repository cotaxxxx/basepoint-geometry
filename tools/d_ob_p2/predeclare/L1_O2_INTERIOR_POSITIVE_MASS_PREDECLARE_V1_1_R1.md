本改訂は、O2 P2 における R1 方式の境界起点を明確にするため、凍結済み O2 事前宣言 v1 に **O2-A3「極限面の起点」**を追加するものである。

この追加は、境界面での恒等式の使用を許可するものであり、O2 の成立を認定するものではない。

### §2．O2-A3：極限面の起点

#### §2.1．使用を許可する既存資産

**境界 R-G 恒等式**

境界面において、\(\rho>0\) かつ \(\mu\ne m\) のほぼすべての \(\mu\) に対し、

\[
G_P(\mu)=G_K(\mu)
\]

が成立する。

この恒等式は、**\(r_{\mathrm{rad}}=1\) の極限面に限って使用する。**

#### §2.2．適用区間

O2 の正質量区間は、凍結済み事前宣言 v1 に従い、

\[
I_+=[-1,1/2]
\]

とする。

固定されたパラメータ領域では、

\[
m\ge\frac{112}{113}>\frac12\ge\mu
\qquad(\mu\in I_+)
\]

である。

したがって、

\[
\boxed{I_+\subset\{\mu<m\}}
\]

が成立し、境界 R-G 恒等式の例外点 \(\mu=m\) は積分区間に含まれない。

ただし、\(\rho=0\) に対応する軸方向の極限は、この恒等式だけでは処理済みとしない。

#### §2.3．K 型正質量の境界極限

O2 が扱う正質量を

\[
M_+(r,\tau)
=
\int_{I_+}G_K(r,\tau,\mu)\,d\mu
\]

と記す。

ここで \(r=r_{\mathrm{rad}}\) とし、その他の変数および正規化は凍結済み v1 と P0–P1 の原典に従う。

**境界における \(G_K\) の定義**

\(G_K(1,\tau,\mu)\) は、closure `c4d49d81` の (C4)–(C5) に規定された、内部からの片側極限（trace）によって定義される境界 K 型密度を指す。

\(I_+\) 上では

\[
D\ge\frac{83}{565}>0
\]

が境界まで成立するため、表面上の積分点は基点に近づかない。この非退化性の下で、内部 K 型の \(r_{\mathrm{rad}}\uparrow1\) による極限は通常の微分による境界評価と一致し、上記の trace 定義に一致する。

**極限と積分の交換**

P1-K1 が扱う拡張された有界閉領域において、K 型密度の連続性が成立すれば、コンパクト性により \(r\uparrow1\) で \(G_K(r,\tau,\mu)\) は境界 trace に一様収束する。

したがって、

\[
\lim_{r\uparrow1}
\int_{I_+}G_K(r,\tau,\mu)\,d\mu
=
\int_{I_+}
\lim_{r\uparrow1}G_K(r,\tau,\mu)\,d\mu
\]

が成立し、

\[
\lim_{r\uparrow1}M_+(r,\tau)
=
\int_{I_+}G_K(1,\tau,\mu)\,d\mu
\]

を得る。

**依存条件：** この極限交換は、P1 補題 3.1–3.2 の成立を前提とする。両補題は現時点で **NOT_BINDING / 外部監査待ち**であり、上記の結論もその条件付きである。

**境界 R-G 恒等式の適用**

§2.1 および §2.2 により、適用条件を満たす境界面では、

\[
\int_{I_+}G_K(1,\tau,\mu)\,d\mu
=
\int_{I_+}G_P(1,\tau,\mu)\,d\mu
\]

となる。

**正規化およびパラメータ領域の照合結果：確認済み**

南側39′、境界 R-G、O2 の正規化は共通であり、

という P 単位を使用する。

根拠は、境界 R-G closure record（`e0f59439`）§4、74–78行である。同記録は、南側の \([-1,1/2]\) における下界が同じ関数 \(G\) についての主張であること、および境界での K 型・P 型の一致を記録している。

また、c_FT 事前宣言 `b3127b4e987f2869392daa3ee0d7b1841380272d` の (F3) は「R-G CLOSED」と記録している。

共通のパラメータ領域は、

したがって、P1 補題 3.1–3.2 に依存する連続性条件が成立する場合、

### §3．使用範囲の制限

本改訂によって許可されるのは、**境界極限における K 型と P 型の同一視、および既存の境界下界の引用のみ**である。

内部領域

\[
\frac78\le r_{\mathrm{rad}}<1
\]

では、引き続き K 型を使用する。

内部で P 型、R·J 型その他の表現へ切り替えることは、本改訂によって許可されない。

凍結済み v1 の switch gate は変更しない。

### §4．軸方向の一様性

境界 R-G 恒等式は \(\rho>0\) を条件とする。

したがって、

\[
\tau\to1,\qquad \rho\to0
\]

の軸方向極限に対する一様性は、別途証明を要する。

本改訂は、軸方向の極限交換、連続性、一様下界を自動的に保証しない。

O2-U-axis は引き続き独立した証明義務として維持する。

### §5．P2 との関係

本改訂は、P2 の R1 方式に対して境界起点の使用を認めるものである。

半径方向の導関数評価、Lipschitz 定数の認証、および内部全域への下界の移送は、P2 の別個の証明義務とする。

特に、

\[
-\partial_rM_+\le L_*
\]

および

\[
L_*<
8S''_{\mathrm{lb}}
=
\frac{635530452759}{102152000000}
\]

は、本改訂によって成立するものではない。

これらは P2 で認証する。

### §6．不変条件

本改訂では、以下を変更しない。

1. O2 の対象量、正規化、パラメータ領域。
2. 正質量区間 \(I_+=[-1,1/2]\)。
3. 内部領域での K 型使用義務。
4. switch gate。
5. O2-U-axis および O2-U-delta。
6. O3 の負部分に関する証明義務。
7. 凍結済み v1 のその他すべての条件。

### §7．失敗時の扱い

以下のいずれかが生じた場合、境界起点の採用は停止する。

- P1-K1 の連続性条件を満たせない。
- P1 補題 3.1–3.2 の必要条件を満たせない。
- 境界 R-G 恒等式の適用条件を満たせない。
- 南側39′と O2 の正規化・パラメータ領域に不一致が判明する。
- 軸方向の一様性に必要な条件を確保できない。

この場合は **FAIL-CLOSED** とし、証明方式の変更には新たな Judge 裁定を必要とする。
