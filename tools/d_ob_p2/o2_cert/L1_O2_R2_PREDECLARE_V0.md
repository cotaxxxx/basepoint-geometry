### 7．積分下界の認証

外側パラメータ箱を \(B\)、内側積分セルを \(J\) とする。

各組 \((B,J)\) に対して、

\[
\Phi_{\xi\xi}(x,y)\ge P_{B,J}(x,y)-\varepsilon_{B,J}
\]

を証明する。

ここで、

\[
x=(\lambda,\tau,r_{\rm rad}),
\qquad
y=(\mu,\theta,t)
\]

であり、\(P_{B,J}\) は有理係数多項式、\(\varepsilon_{B,J}\) は非負の有理誤差上界である。

この不等式は、セル全域で成立しなければならない。

#### 7.1．Bernstein 認証

各箱を単位立方体へ有理アフィン変換し、必要な多項式不等式を Bernstein 基底で表す。

非負性を主張する場合は、全 Bernstein 係数の非負性など、独立に検証可能な十分条件を使用する。

係数の非負性が得られない場合、それだけで元の関数が負であるとは判断しない。

ただし、証明書として成立しない箱を PASS として扱ってはならない。

#### 7.2．積分と誤差

各内側セルで、

\[
\int_J\Phi_{\xi\xi}\,dy
\ge
\int_JP_{B,J}\,dy
-
\varepsilon_{B,J}|J|
\]

を使用する。

多項式の積分は有理数として厳密に処理する。

\(\pi\)、平方根、三角関数、\(g\) の近似誤差は、すべて下界側に伝播させる。

ここでいう「外向き丸め」とは、浮動小数点の丸め結果を証拠にすることではなく、**厳密な有理上下包囲によって真値を包含すること**を意味する。

#### 7.3．外側箱の下界

内側セルを合算し、外側箱 \(B\) に対する有理下界

\[
\underline M(B)
\]

を構成する。

証明すべき命題は、

\[
\boxed{
\forall x\in B,\qquad
M_+(x)\ge\underline M(B)
}
\tag{R2-8}
\]

である。

全ての外側葉箱について、

\[
\boxed{
\underline M(B)\ge h_*>0
}
\tag{R2-9}
\]

を証明できた場合に限り、R2 の正質量認証を PASS とする。

\(h_*\) は全箱共通の正の有理数でなければならない。

**重要：** \(P_{B,J}\) の係数、近似次数、誤差予算、実際の \(h_*\) は v0 では未確定である。したがって、この節は証明書の仕様であって、完成した証明書ではない。
