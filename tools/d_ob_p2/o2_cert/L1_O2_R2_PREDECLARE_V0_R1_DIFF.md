## M3．距離 \(D_\xi\) の強い下界

§3 の直後に、次の必須補題を追加します。

### R2-L1：水平距離と高さの差を保持する下界

**補題 R2-L1**

原典 P0 の定義のもとで、

\[
\boxed{
D_\xi^2
\ge
(a-|\xi|)^2+(\lambda\mu-z)^2
}
\tag{R2-L1}
\]

が成立する。

**証明**

原典より、

\[
D_\xi^2
=a^2+\xi^2+(\lambda\mu-z)^2-2\xi a\cos\phi.
\]

ここで、

\[
a\ge0,\qquad |\cos\phi|\le1
\]

なので、

\[
-2\xi a\cos\phi\ge-2|\xi|a.
\]

したがって、

\[
\begin{aligned}
D_\xi^2
&\ge a^2+\xi^2-2a|\xi|
+(\lambda\mu-z)^2\\
&=(a-|\xi|)^2+(\lambda\mu-z)^2.
\end{aligned}
\]

よって、

\[
\boxed{
D_\xi
\ge
\sqrt{(a-|\xi|)^2+(\lambda\mu-z)^2}
}.
\]

証明終。

この補題は \(\mu=-1\) を含む \(I_+\) 全域で成立し、\(r_{\rm rad}=1\)、\(\tau=1\) においても有効である。

#### R2 における使用規則

証明書では、まず R2-L1 を使用して、各パラメータ箱・積分セルに対応する \(D_\xi\) の有理下界を構成する。

\[
\underline D(B,J)>0
\]

を有理数として認証し、

\[
D_\xi\ge\underline D(B,J)
\]

を各セル全域で保証する。

この下界を、積分核に現れる

\[
D_\xi^{-1},\quad D_\xi^{-3},\quad D_\xi^{-5}
\]

などの評価に利用する。

必要に応じて、R1 から継承した三階微分の \(D_\xi^{-7}\) にも適用できる。

ただし、R2-L1 の右辺に含まれる

\[
a=\sqrt{1-\mu^2}
\]

および

\[
|\xi|
\]

の区間評価では、依存関係を無視して不当に強い下界を作ってはならない。

特に、区間全体で

\[

\]

の符号が確定しない場合、その平方を端点値だけから評価することは認めない。

有理区間による正しい平方の下界、または Bernstein 認証を使用する。

従来の

\[

\]

は、全域で有効な保険的下界として保持する。

**R2-L1 自体は紙上で証明済み。ただし、これから得られる具体的な有理下界は P2-b で固定する。**

したがって、現段階では \(D_\xi\ge0.7\) 等の数値的主張を採用しない。

## M4．\(t\) 積分の二方式を追加

§7 に、以下の節を追加します。

### 7.4．\(t\) 積分の解析的簡約

R2 は、6変数の積分を常に直接評価することを要求しない。

原典 P1-K3 の K 型表示を保持する限り、以下の二方式を使用してよい。

どちらの方式をどの領域で使用するかは、P2-b の事前宣言で固定する。

#### 方式 R2-T1：軸から離れた領域

ある有理数

\[
\frac78\le\tau_1<1
\]

を選び、

\[
\tau\le\tau_1
\]

の領域を考える。

この領域では、

\[
\rho=r_{\rm rad}\frac{1-\tau^2}{1+\tau^2}.
\]

したがって、

\[
\rho\ge
\frac78\frac{1-\tau_1^2}{1+\tau_1^2}
=:\rho_{\min}>0.
\]

微積分学の基本定理より、

\[
\begin{aligned}
\int_{-1}^{1}
\Phi_{\xi\xi}(t\rho,z)\,dt
&=
\frac1\rho
\int_{-\rho}^{\rho}
\Phi_{\xi\xi}(\xi,z)\,d\xi\\
&=
\frac{\Phi_\xi(\rho,z)-\Phi_\xi(-\rho,z)}{\rho}.
\end{aligned}
\]

よって、

\[
\boxed{
M_+
=
\frac12
\int_{-1}^{1/2}
\int_0^\pi
\frac{\Phi_\xi(\rho,z)-\Phi_\xi(-\rho,z)}
{\rho}
\,d\phi\,d\mu
}
\tag{R2-T1}
\]

となる。

この表示では \(t\) 積分が消え、外側3変数と内側2変数の計5変数になる。

\[
\rho\ge\rho_{\min}>0
\]

が保証されているため、\(\rho\) による除算は正当化される。

**禁止事項：** この表示を \(\tau=1\) に直接適用してはならない。

#### 方式 R2-T2：軸近傍

\[
\tau\ge\tau_1
\]

の領域では、FTC 表示を維持する。

\[
f(\xi)=\Phi_{\xi\xi}(\xi,z)
\]

と置く。

\(f\) が必要な階数まで微分可能であれば、\(\xi=0\) を中心とする Taylor 展開を使用できる。

二次の剰余を含む表示では、

\[
f(t\rho)
=
f(0)+t\rho f'(0)
+\frac{t^2\rho^2}{2}f''(\eta_t)
\]

となる。ただし、\(\eta_t\) は \(0\) と \(t\rho\) の間にある。

積分すると、

\[
\int_{-1}^{1}t\,dt=0
\]

なので、奇数次の項が消える。

したがって、

\[
\boxed{
\int_{-1}^{1}f(t\rho)\,dt
=
2f(0)+E_{\rm axis}
}
\tag{R2-T2}
\]

であり、

\[
\boxed{
|E_{\rm axis}|
\le
\frac{\rho^2}{3}
\sup_{|\xi|\le\rho}|f''(\xi)|
}
\tag{R2-T2-E}
\]

が成立する。

ここで、

\[
f''=\Phi_{\xi\xi\xi\xi}
\]

である。

この方式では、

\[
\rho^2\le\rho_b^2\le
\left(\frac{15}{113}\right)^2
\]

が利用できる。

さらに \(\tau\ge\tau_1\) を利用すれば、より小さい有理上界を設定できる。

**追加の解析的義務：**

R2-T2 の二次剰余を採用する場合、

\[
\Phi_{\xi\xi\xi\xi}
\]

の存在と一様有界性を証明し、その有理上界を事前宣言しなければならない。

この導関数には、一般に \(g^{(4)}\) が現れる。

したがって、§5 の \(g',g'',g'''\) までの包囲だけでは R2-T2 の二次剰余を認証できない。

P2-b では、次のいずれかを選択する。

- \(g^{(4)}\) を含む四階微分の有理包囲を追加する。
- 四階微分を使用せずに、偶数成分の剰余を直接有理包囲する別の厳密な方式を宣言する。

いずれの場合も、未認証の Taylor 剰余を証明書に使用してはならない。

#### 方式選択の凍結条件

P2-b では、

\[
\tau_1,\qquad \rho_{\min}
\]

を有理数で固定する。

また、R2-T1 と R2-T2 の適用領域、境界の被覆、関数近似次数、剰余評価、独立検証方法を事前に固定する。
