# c_FT certificate — offline reproduction kit for the CHAT AUDIT independent re-run

Purpose: allow the CHAT AUDIT independent re-run without network access to GitHub.  This file is NOT evidence and does not modify the evidence
commit 87b7c5af.  It carries the frozen source byte-for-byte (base64) and the expected hashes.

Source: tools/d_ob_p2/ftq_cert/cft_cert.py, commit 31368987ca2a9b99d8765a418b45ba26fd81a925, git blob ea4dc1475b03a993fbaf5aa397bea2feb62f4960,
SHA-256 0e4161ff20eb1934e088bca569e092344cae72ee68af9a4d906fd1953ae95b98, 5836 bytes.
Expected outputs (Code run, Python 3.11.15, SymPy 1.14.0): stdout.txt SHA-256 12968e4a258b5d638746319ed045611308df16e4608f9035a9ef95a4abab889b (1893 bytes, 21 lines);
stderr.txt empty (SHA-256 e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855); exit code 0.
Dependency: only `sympy` (and the standard library).  Note: byte identity of stdout is expected across SymPy versions because the printed lines
contain only Fractions, fixed strings and float formatting with fixed precision; a SymPy version difference is a possible (not expected) source of
deviation in the symbolic checks' PASS/FAIL only.

Procedure (in a new empty directory):
```
python3 - <<'PY'
import base64, hashlib
data = base64.b64decode(open('cft_cert.b64').read())
assert hashlib.sha256(data).hexdigest() == '0e4161ff20eb1934e088bca569e092344cae72ee68af9a4d906fd1953ae95b98'
open('cft_cert.py', 'wb').write(data)
PY
python3 -I cft_cert.py > stdout.txt 2> stderr.txt; echo "exit=$?"
sha256sum stdout.txt stderr.txt

#           e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855  stderr.txt
```
