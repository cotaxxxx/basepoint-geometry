# 回転楕円体族（扁平→球→扁長）の中心係数 走査 — 探索的・非認証

`family_scan.py` は Paper 1 の付録B/Cの式を使わず、`E_K(p)` の定義から直接
中心 Hessian の赤道方向係数 `Q(a)`、軸方向係数 `Qz(a)`、軸方向4次係数 `Hz4(a)` を
数値評価する（mpmath、Gauss–Legendre、`K_a = {x²+y²+z²/a² ≤ 1}`）。
**証明物件ではない。** 族論文の設計と Arb 認証の目標区間設定のための探索値である。

## 結果（2026-09-06、dps 30–40、60/90 節点で全桁一致）

| 事実 | 値 |
| --- | --- |
| 球 `a=1` | `Q = Qz = 4/3`、`H4 = Hz4 = −16/3`（等方性の検算） |
| 扁平側・軸方向臨界値 `a_z`（`Qz(a_z)=0`） | `0.407958860300946364249106` |
| `Qz'(a_z)` | `+14.9680106925` |
| `Hz4(a_z)` | `−56.6221269617` |
| `Q(a_z)` | `+1.5524`（赤道方向は正のまま → 停留点は軸上に閉じ込め） |
| 扁長側・赤道方向臨界値 `a_c`（`Q(a_c)=0`、Paper 1 で認証済） | `4.72438340452113340672…` |
| `Qz(a_c)` | `+0.0942`（軸方向は正のまま） |
| `ln a_z`, `ln a_c` | `−0.8966`, `+1.5527`（球を中心に非対称） |

符号の全域像（`a ∈ [0.01, 50]` の標本点）：`Q>0` on `(0, a_c)`、`Q<0` beyond；
`Qz<0` on `(0, a_z)`、`Qz>0` beyond（`a→∞` で `0+`）。中心 Hessian の符号反転は
族全体で **ちょうど2回**（軸方向 `a_z`、赤道方向 `a_c`）と見える。

## 分岐の型

- `a_z`（扁平）：`t² = 6Qz/|Hz4|` より軸上の停留点対 `±t` が **`a > a_z`（球側）** に存在。
  等方型 `D∞h → C∞v`、成分は0次元・2個、`σ_h` で入れ替わる `Z₂` 軌道。
- `a_c`（扁長）：`r² = 6Q/|H4|` より赤道停留円が **`a < a_c`（球側）** に存在。
  等方型 `D∞h → C∞v`（円上の各点）、成分は1次元・1個。

いずれも劣臨界（非自明枝は中心が局所極小である側に出る）。

## 認証に必要な物件（Paper 1 の Qz チェーンの鏡像）

1. `Qz` の零点の20桁端点符号認証（`prolate_ac_arb_certificate.py` の `qz_integrand` 版）
2. `Qz' < 0`… ではなく **`Qz' > 0`** と `Hz4 < 0` の区間認証（`a_z` を含む区間）
3. 軸方向4次核 `Fz''''(0)` の記号監査（`prolate_H4_symbolic_audit.py` の軸方向版）
4. **`Q > 0`** の区間認証（横方向閉じ込め：補題6.1 の鏡像 `∂_rE = rG`, `G(a_z,0)=Q(a_z)>0`）
5. `a<1` でも同じ 0F1 正則化が使えることの確認：`β = arctan((a−a⁻¹)sc)` は `a<1` で負になるが
   `z=β²` と `S=sinβ/β` は偶関数なので式は不変。`W, ℓ` の下界は `min(1,a²)` に置き換える。

実行: `python3 family_scan.py`（要 mpmath、約2秒）。

## 2026-09-06 追記：体積一定**三軸**楕円体族の形状平面と中心分岐集合（探索的・倍精度）

研究目的（汎関数をレンズとして基点変動で停留構造を抽出し、形状変形に沿った変化を追う）に
従えば、回転楕円体の直線は形状空間の一部にすぎない。体積一定楕円体族
`{x²/a₁²+y²/a₂²+z²/a₃² ≤ 1, a₁a₂a₃=1}` は `u_i = ln a_i, Σu_i=0` により**2次元平面**であり、
軸の置換で `S₃`（6重）対称、3本の鏡映軸が回転楕円体（`a_i=a_j`）である。

`triaxial_center_scan.py`（Gauss–Legendre 96×192、5点差分、倍精度）で中心 Hessian の
3主係数 `Q_i = ∂²E/∂x_i²(0)` を走査し、`Q_i=0` の曲線を描いた
（`triaxial_center_bifurcation_set.png`、データ `triaxial_center_Q.npz`）。

**検算**：球で `Q_i = 4/3`；回転楕円体直線上の零点は `a₃/a₁ = 0.408`（`Q_3`）と `4.725`
（`Q_1=Q_2`）で、mpmath の `a_z, a_c` を再現（残差 `≲6e−9`）。

**構造**（座標 `p=(u₁−u₂)/√2`, `q=√(3/2)·u₃`、原点＝球）：

| 対象 | 位置 | 意味 |
| --- | --- | --- |
| index 0 領域（中心が局所極小） | 球を囲む**凸な曲線三角形** | 「球に近い形」の領域の正確な境界 |
| 3頂点 | `r=1.268`、方位 90°/210°/330°（3本の回転楕円体軸上） | **扁長点 `a_c`**：`Q_i=Q_j=0` の corank-2 点。対称性が二重零を強制 |
| 3辺の中点 | `r=0.731`、方位 270°/30°/150° | **扁平点 `a_z`**：corank-1 |
| 辺 | 直線三角形の内接半径 0.634 より外側（0.731）に膨らむ | 対称性を破ると軸方向退化は**より小さい**変形で起こる |
| 頂点での交角 | `Q_1=0` と `Q_2=0` が **≈83°** で横断的に交差 | `D∞h→D2h` による赤道二重零の展開は非退化 |
| index 2 領域 | 各頂点の外側（2本の曲線の間） | 扁長を超えた側、両赤道方向が負（Paper 1 の `a>a_c`） |
| index 3 | 走査範囲（軸比 ≤ 60）に**存在しない** | 中心は極大にならない |

`r = |ln(軸比)|·√(2/3)` なので `a_c ↦ 1.5527·0.8165 = 1.268`、`a_z ↦ 0.8966·0.8165 = 0.732` と整合。

**分裂の線形係数**：`a₃/√(a₁a₂)=a_c` を固定して `δ=ln(a₁/a₂)` を動かすと
`dQ_1/dδ ≈ +1.18`、`dQ_2/dδ ≈ −1.29`（`a₁>a₂` のとき **短い赤道半軸方向**が先に退化）。
局所ピッチフォークとして読むと、回転対称の停留円は三軸化で
「短軸方向の `±` 対」と「長軸方向の `±` 対」に分かれ、異なるパラメータで中心へ吸収される
—— Paper 1 Outlook の「4点への分裂」の局所的な内訳である。

**族論文への含意**：
- 「扁平→球→扁長」の1次元族は、この三角形の**1本の対称軸に沿った断面**として位置づけられる。
  断面上の2つの分岐点（頂点と辺中点）は、平面上では**曲線**の特別な点である。
- ラベル体系（成分次元・個数・等方型・核次元）の変化は、平面上で「辺を横切る（corank 1、
  `Z₂` 対の吸収）」と「頂点を通る（corank 2、回転対称のとき円の収縮）」の2種に整理できる。
- 認証は回転楕円体上の2点（既存チェーンの鏡像）で行い、平面上の曲線は診断として提示する
  —— Paper 1 と同じ節度で、しかし「指紋が変形でどう変わるか」の全体像を1枚の図で示せる。
