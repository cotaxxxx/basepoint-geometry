# 回転楕円体族（扁平→球→扁長）の中心係数 走査 — 探索的・非認証

`family_scan.py` は Paper 1 の付録B/Cの式を使わず、`E_K(p)` の定義から直接
中心 Hessian の赤道方向係数 `Q(a)`、軸方向係数 `Qz(a)`、軸方向4次係数 `Hz4(a)` を
数値評価する（mpmath、Gauss–Legendre、`K_a = {x²+y²+z²/a² ≤ 1}`）。
**証明物件ではない。** 族論文の設計と Arb 認証の目標区間設定のための探索値である。

## 結果（2026-09-06、dps 30–40、60/90 節点で全桁一致）

| 事実 | 値 |
| --- | --- |
| 球 `a=1` | `Q = Qz = 4/3`、`H4 = Hz4 = −16/3`（等方性の検算） |
| 扁平側・軸方向臨界値 `a_z`（`Qz(a_z)=0`） | `0.407958860300946364249106` |
| `Qz'(a_z)` | `+14.9680106925` |
| `Hz4(a_z)` | `−56.6221269617` |
| `Q(a_z)` | `+1.5524`（赤道方向は正のまま → 停留点は軸上に閉じ込め） |
| 扁長側・赤道方向臨界値 `a_c`（`Q(a_c)=0`、Paper 1 で認証済） | `4.72438340452113340672…` |
| `Qz(a_c)` | `+0.0942`（軸方向は正のまま） |
| `ln a_z`, `ln a_c` | `−0.8966`, `+1.5527`（球を中心に非対称） |

符号の全域像（`a ∈ [0.01, 50]` の標本点）：`Q>0` on `(0, a_c)`、`Q<0` beyond；
`Qz<0` on `(0, a_z)`、`Qz>0` beyond（`a→∞` で `0+`）。中心 Hessian の符号反転は
族全体で **ちょうど2回**（軸方向 `a_z`、赤道方向 `a_c`）と見える。

## 分岐の型

- `a_z`（扁平）：`t² = 6Qz/|Hz4|` より軸上の停留点対 `±t` が **`a > a_z`（球側）** に存在。
  等方型 `D∞h → C∞v`、成分は0次元・2個、`σ_h` で入れ替わる `Z₂` 軌道。
- `a_c`（扁長）：`r² = 6Q/|H4|` より赤道停留円が **`a < a_c`（球側）** に存在。
  等方型 `D∞h → C∞v`（円上の各点）、成分は1次元・1個。

いずれも劣臨界（非自明枝は中心が局所極小である側に出る）。

## 認証に必要な物件（Paper 1 の Qz チェーンの鏡像）

1. `Qz` の零点の20桁端点符号認証（`prolate_ac_arb_certificate.py` の `qz_integrand` 版）
2. `Qz' < 0`… ではなく **`Qz' > 0`** と `Hz4 < 0` の区間認証（`a_z` を含む区間）
3. 軸方向4次核 `Fz''''(0)` の記号監査（`prolate_H4_symbolic_audit.py` の軸方向版）
4. **`Q > 0`** の区間認証（横方向閉じ込め：補題6.1 の鏡像 `∂_rE = rG`, `G(a_z,0)=Q(a_z)>0`）
5. `a<1` でも同じ 0F1 正則化が使えることの確認：`β = arctan((a−a⁻¹)sc)` は `a<1` で負になるが
   `z=β²` と `S=sinβ/β` は偶関数なので式は不変。`W, ℓ` の下界は `min(1,a²)` に置き換える。

実行: `python3 family_scan.py`（要 mpmath、約2秒）。
