## 2. 修正事項（軽微だが必須）

### 2.1 実解析性の補題を復元されたい

§4 末尾「The functions are real analytic near the parameter range considered here.」と
§7「Real analyticity implies continuity of H.」が、解析性に関する記述のすべてである。
日本語版の補題3.2 は、R1 で指摘した穴（4次展開・`∂_rE=rG(a,r²)` の因数分解・
`∂_zE=zH` の Hadamard 分解と `H` の同時連続性）を一箇所で埋める役割を持ち、その証明は
`arccos²x = 2(1−x)+(1−x)²/3+⋯` による `x=1` での解析接続、凸性による `x=−1` からの分離、
分母の一様下界、項別積分の6行であった。

**要求**：補題として復元する（英語で6〜8行）。§8 の "Proof structure" 第1・3・4段はいずれも
この補題を前提にしているので、参照先がないと証明の骨格が宙に浮く。

### 2.2 認証された核の正典表示を付録として復元されたい

本稿は `Q, H₄, Q_z` を §4 のテイラー係数として**定義**するが、Arb が実際に積分した
被積分関数 ―― `B₂(θ,a)`、`A₄, A₂, A₀` と `B₄`、`Fz″(0)` ―― はどこにも書かれていない。
§9 は `h₁…h₄` の 0F1 表示のみを与える。したがって読者は、命題6.1・§7 の包絡が
**どの積分の**包絡なのかを論文から知ることができず、リポジトリを読むしかない。

Experimental Mathematics の読者層はまさにその式を見たい層である。日本語版の付録B.2–B.3・
付録C はあわせて半頁に収まる。**要求**：付録に (3)(4)(5) の三式と、`Q_z` の5区間包絡表を復元する。
併せて `Q(a)=½∫₀^{π/2} s B₂ dθ` 等、テイラー係数と積分の対応を一行ずつ与える。

### 2.3 c の包絡の下端が内向きに丸められている

`c = 6Q′(a_c)/H₄(a_c)` の包絡 `[0.3415, 0.4517]` は、`a_c∈[4.72,4.73]` の表示区間
`Q′∈[−0.10438,−0.08480]`、`H₄∈[−1.48998,−1.38666]` から

```
lower = 6·0.08480/1.48998 = 0.34148…  → 外向き 0.3414
upper = 6·0.10438/1.38666 = 0.45164…  → 外向き 0.4517
```

となる。上端はブランチのコミット `c198581` で 0.4516 → 0.4517 に**外向きへ修正済み**だが、
下端 0.3415 は依然として**内向き**（切り上げ）である。「rigorously enclosed」と書く以上、
`[0.3414, 0.4517]` とされたい。なお `SUBMISSION_CHECKLIST.md` は `[0.3415,0.4516]` の
旧値のままで、tex と食い違っている。

### 2.4 定義2.1 の「ラベル保存局所自明化」

R2 で追加した明示的定義（各ファイバーの局所連結成分を連続に同一視し個数と各ラベルを
保存するファイバー同相）が英語版で再び落ちている。一文で復元されたい。
定義2.1 は主定理の判定基準そのものである。

### 2.5 定理8.1 の記述の精度

- `Crit(E_a) = {0} ⊔ C_a (a<a_c)` の行に、`a>a_c` の行と同様 "sufficiently close to `a_c`"
  を付す。また日本語版の「局所モデル `J₀×U₀` を固定し、その内部で縮小」という構成を
  一文で述べると、「十分小さい近傍」の量化子の順序が明確になる。
- 要旨の "changes topology" は緩い。実際に示すのは成分数・成分次元・核次元というラベルの
  変化なので、"changes its local component structure" 等が正確。

## 3. 推奨事項（投稿先を考慮して）

### 3.1 実験段階を見せる

本稿の主張は「実験が定理を導いた」ことにあるが、実験そのものはどこにも示されていない。
図1 は模式図であり、探索段階の数値（`Q(a)` の標本値、数値的に追跡した半径 `r(a)`）は
一切登場しない。Experimental Mathematics では、**非認証と明記したうえで**探索データを
示すことが歓迎される。提案：図1 に数値追跡した枝を薄線で重ね「exploratory, non-certified」と
注記する；あるいは `a∈{4.5,…,4.75}` 数点の `Q(a)` 高精度値を小表で示し、
「これらは証明物件ではない」と付す（`prolate_cap_stage1_report.json` が既にある）。

### 3.2 反復の整理

「global continuation is not a premise」が §1・§10.2・§11 に三度現れる。§10.2 に集約し、
他は一文で参照する。§10.1（fail-closed）は良い記述だが §5 と重なる。

### 3.3 リポジトリ側の整備

- 英語ソースは `paper1-certchain-202609` ブランチにあり `main` に未統合。投稿前に main へ
  取り込み、[10] と "Data and code availability" の正典 commit を**原稿ソースを含む commit**
  に更新するか、証明物件の commit（abf704b）と原稿の commit を区別して両方記す。
- `SUBMISSION_CHECKLIST.md` の c 包絡を tex に合わせる（§2.3）。
- 日本語版 `manuscript.tex` は 2026-08-23 版のまま。英語版を正典とするなら README にその旨を。

### 3.4 その他

- §6 の `Q′`・`H₄` 包絡は5区間分を列挙しているが、命題6.1 の証明に要るのは `a_c` を含む
  `[4.72,4.73]` の行と、一意性のための全区間の符号だけである。表形式に戻すと読みやすい。
- 「Python 3.13.14」等の環境記述は再現性の観点で良いが、cap 系の環境（Python 3.12/3.13）が
