楕円体面 `(sinθcosφ, sinθsinφ, a cosθ)` 上で高精度求積（mpmath, dps=45,
Gauss–Legendre 70点＋φ方向は多項式次数を利用した厳密平均）を行った。

**解析的整合性チェック（査読者による手計算）** — いずれも論文の記述と厳密に一致した。

- `C = a/√(Wℓ)` と `tanβ = (a − a⁻¹)sc` は、`Wℓ = a² + (a²−1)²s²c²` から厳密に導かれる。
- `h(x) = arccos²x`、`x = cosβ` について
  `h₁ = −2β/sinβ = −2/S`（`S = ₀F₁(;3/2;−β²/4) = sinβ/β`）。論文B.1と一致。
- `h₂ = 2(sinβ − βcosβ)/sin³β`。一方 `₀F₁(;5/2;−β²/4) = 3(sinβ−βcosβ)/β³` なので
  `2T/(3S³)` はこれに厳密に等しい。論文B.1と一致。
- 球 `a = 1` では `B₂ = 4 − 2s²` となり `Q(1) = 4/3`。査読者の数値求積も
  `1.3333333333333333333…` を返し、45桁一致。
- 式(5) の正規化 `Qz(a) = ∫₀^{π/2} s Fz″(0) dθ` は、`3Vol = 4πa`、面積要素 `s√W`、
  `d·n = a(1 − wt)` から `√W` が相殺されることで定義から再導出でき、係数まで一致する。

**結論：論文の数式・数値・符号判定に誤りは検出されなかった。**
特に、`arccos` の分岐点（`γ → 1`、すなわち `sc = 0`）を `β` と `₀F₁` に書き換える
付録B.1の端点正則化は、被積分関数を複素近傍で真に解析的にしており、
Arb/Acb の適応求積が厳密包絡を返すための前提を満たす。設計として正しい。

## 4. 修正推奨事項

### 4.1 認証包絡の精度が不均一で、その理由が説明されていない

`Q` は有効15桁、`Q'` は有効2桁、`H₄` は約7%幅、`Qz` は約10%幅と、桁数が三桁以上
食い違う。これは `Q` が**点評価**、他が**`a` 区間上の区間評価**（区間拡大を含む）で
あることに由来すると推測されるが、本文にも付録にも説明がない。読者は認証の失敗や
実装の不備を疑う。一行の注記で足りる。

### 4.2 分岐の向き・モース指数が明示されていない（自明に補える）

既に認証済みの符号から次が直ちに従うのに、本文はどこにも書いていない。

- `Q(1) = 4/3 > 0`（査読者計算）かつ `[4.7,4.75]` で `Q' < 0` ⇒ `a < a_c` で `Q > 0`、
  `a > a_c` で `Q < 0`。
- したがって停留円 `C_a` は `Q > 0` 側（`a < a_c`）に現れ、`r² = 6Q/|H₄|`。
  中心は `a < a_c` で局所**極小**、円は径方向**極大**の輪。
- `a > a_c` では `Qz > 0`・赤道方向固有値 `< 0` ゆえ中心は**鞍点**となり、
  中心は局所極小でなくなる。

すなわち本分岐は **subcritical（劣臨界）** な O(2)-pitchfork である。定義2.1 は
ラベルに「法方向モース指数」を挙げながら本文で一度も計算せず、§6 では
「停留円の全法方向 Hessian の非退化性は主定理には用いない」と退避している。
上記を明記すればラベル表は完成し、定義との不整合も解消する。

またこの点は §9 の中心理論との接続に直結する。radial center 系の文献が扱うのは
主として**大域的最小点**であり、`a > a_c` で中心が最小点でなくなる以上、
「最小点はどこへ行くのか」は読者が必ず抱く問いである。局所定理の射程外である旨を
一段落で明示されたい（§8.2 の限定は認証範囲の話であって、この問いへの回答ではない）。

### 4.3 系6.2 に `a = a_c` の場合が抜けている

`a < a_c` と `a > a_c` のみが書かれている。陰関数定理の局所一意性から
`a = a_c` でも `Crit(E_a) ∩ U = {0}` が従うので、三つ目の行として明記されたい。
主定理のラベル比較を読者が自力で完成させる必要がなくなる。

### 4.4 定義2.1 の「局所自明化」が未定義

「ラベルを保存する局所自明化」が本論文の判定基準そのものであるにもかかわらず、
定義されていない。`π` と可換な同相写像 `𝒮 ∩ (I×U) ≅ I × (𝒮_{λ₀} ∩ U)` であって
各ファイバー上でラベルを保つもの、といった明示的定義を与えられたい。
定義2.1 は本論文の主張の骨格なので、ここは厳密に書く価値がある。

### 4.5 位置づけの明確化（§9 の強化）

本現象は `D∞h`（実質 `O(2) × ℤ₂`）同変分岐の劣臨界 pitchfork であり、標準理論
（Golubitsky–Stewart–Schaeffer, 文献[4]）の枠内にある。§9 は「新規性を一般的な
`D∞h` または `O(2)` 分岐理論そのものに置くべきではない」と正しく断っているが、
**本文中で[4]を一度も引用していない**。標準形を一行で提示し、[4]を引いたうえで
「本稿の寄与は具体的凸幾何汎関数における区間認証済みの実例である」と述べる方が、
かえって主張が強くなる。現状の書き方では「基点分岐」が既知機構の言い換えに見える。

## 5. 軽微な指摘

1. **未引用文献**：本文で番号引用されているのは[10]のみ。[1][2][6]（錐体積測度・

2. **命題3.1（相似不変性）が使われていない**：赤道半径を1に正規化する根拠として
   §4 で引くか、Remark に格下げすること。
3. **環境記述の不一致**：付録Aは「Python 3.11/3.13」、リポジトリ README は
   「Python 3.13.5」と記す。実行環境を一意に固定されたい。
4. **記法の揺れ**：`Q` と `B₂`、`H₄` と `B₄` が併存し、§4 の `E_a(r)` は
   `E_a` が `r` の一変数関数であるかのように書かれている（実際は径方向への制限）。
   `E_a|_{赤道}(r)` 等と区別されたい。
5. **補題6.1 の引数表記**：`H(a,x,y,z²)` は `z²` を第4引数に取る書き方で、
   本文の説明なしには読みにくい。Hadamard の補題を明示的に引用し、

6. **§6 の nullity=2 の議論**：`D∞h` 対称性から中心 Hessian が
   `diag(Q, Q, Qz)` と対角化される点を明記すれば、`nullity ≥ 2` から
   `= 2` への移行が自明になる。
7. **命題5.1・5.2 の「証明」**：現状は認証結果の要約であり、証明の体裁を成していない。
   「`Q` の連続性 ⇒ 中間値定理 ⇒ `[4.7,4.75]` 上の `Q' < 0` による一意性」という
   論理鎖を明示的に書き下されたい。特に、Arb の適応求積が厳密包絡を返すために
   必要な**被積分関数の複素近傍における解析性**（§2 で述べたとおり付録B.1の正則化に
   よって実際に成立している）を、仮定として明示することを強く勧める。

## 6. 長所（評価すべき点）

- **数値の再現性が極めて高い**。第三者による完全独立実装が、臨界軸比を20桁、
  `Q` の値を15桁で再現した。この種の計算機援用論文としては上位の水準にある。
- **端点正則化の設計が正しい**。`arccos` の分岐点を `β = arctan((a−a⁻¹)sc)` と
  `₀F₁` 超幾何に押し込む付録B.1は、区間演算を厳密たらしめるための本質的工夫であり、
  単なる数値的便宜ではない。この設計意図を本文でもう少し前面に出してよい。
- **射程の自己限定が誠実**。§8.2・§9・§10 で「全域完全性を仮定しない」「一般理論を
  確立するものではない」と繰り返し明示しており、過剰主張がない。
- **`Qz` の導入は本質的な前進**である。これがあって初めて、停留円が二次元還元の
  産物ではなく三次元臨界集合の局所連結成分であることが言える。だからこそ §3.1 の
  物件不在が致命的になる。
