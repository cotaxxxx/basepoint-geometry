## 4. 軽微な指摘

### 4.1 付録A・付録Dに重複するテキストランがある

PDF のテキスト配置を検査したところ、p.8（付録A の箇条書き）と p.11（付録D）で、
**同一内容がほぼ同じ座標に二重に配置されている**（例：p.11 で y=744 と y=742、
y=528 と y=512 に同じ文が現れる）。一方のランは日本語のグリフが正しく
Unicode 化されておらず、本査読者の抽出では文字化けする。

視覚的に二重描画されているのか、片方が不可視レイヤなのかは本査読環境では判別できない。
最終稿の組版出力を目視確認し、不要なランを除去されたい。

### 4.2 h-chain 監査は β∈(0,π) 上の恒等式である

`prolate_h_chain_symbolic_audit.py` は `|sin β| = sin β`、`arccos(cos β) = β` を用いるため、
確立されるのは `β ∈ (0,π)` 上の恒等式である。積分の端点 `θ = 0, π/2` では `sc = 0` すなわち
`β = 0` となり、左辺（`arccos²` の導関数）はそこで特異、右辺（0F1 表示）は整関数である。
両者の一致は `β = 0` へは**解析接続として**及ぶ ―― これこそが B.1 の端点正則化の要諦である。

付録B.1 は既に「`S = sinβ/β` は正の下界を持つ」と述べており実質は押さえられているが、
「監査は `β∈(0,π)` で恒等式を与え、`β=0` へは 0F1 側の整性により連続に延びる」と
一文添えれば、鎖の最後の継ぎ目まで明示される。監査スクリプトの docstring にも同記述を
置くことを勧める。
