# 4-π研究

## 位置づけ

「4-π研究」は、幾何双対位相の原点を扱う独立研究区分である。

正方形と内接円の面積差

\[
4-\pi
\]

が、正方形の動径方向と境界法線方向のずれを測るエネルギーと厳密に一致する理由を解明し、その一致を一般の接多角形、正多角形、星形凸領域および高次元へ拡張する。

総論・各論の上流に位置する原点研究であり、現在の三次元汎関数

\[
E_K(p)
\]

へ至る発想の二次元原型を記録する。

## 中心命題

原点を内心とし、内接円半径を \(r\) とする凸接多角形 \(P\) の動径関数を \(\rho_P(\theta)\) とする。このとき、頂点に対応する有限個の角度を除いて、

\[
\boxed{
|P|-\pi r^2
=
\frac{r^2}{2}
\int_0^{2\pi}
\left|\partial_\theta\log\rho_P(\theta)\right|^2\,d\theta
}
\]

が成立する。

動径方向と外向き法線方向の符号付き角を \(\alpha(\theta)\) とすれば、

\[
\tan\alpha(\theta)
=-\partial_\theta\log\rho_P(\theta)
\]

であるから、同値に

\[
\boxed{
|P|-\pi r^2
=
\frac{r^2}{2}
\int_0^{2\pi}\tan^2\alpha(\theta)\,d\theta
}
\]

となる。

単位円に外接する正方形では \(|P|=4\)、\(r=1\) なので、

\[
\boxed{
4-\pi
=
\frac12
\int_0^{2\pi}
\left|\partial_\theta\log\rho_\square(\theta)\right|^2\,d\theta
=
\frac12
\int_0^{2\pi}\tan^2\alpha(\theta)\,d\theta
}
\]

を得る。
