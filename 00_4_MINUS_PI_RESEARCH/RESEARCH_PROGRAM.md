# 4-π研究：研究計画

## 1. 最終問題

4-π研究の最終問題は、

\[
4-\pi
\]

という数値を計算することではない。

解くべき問題は、

\[
\boxed{
\text{なぜ正方形と円の面積欠損が、動径–法線角のエネルギーと一致するのか}
}
\]

を、一般理論として説明することである。

## 2. 第一段階：二次元の完全整理

### 2.1 星形凸領域の境界恒等式

適切な正則性の下で

\[
B_\Omega-2\pi
=
\int_{S^1}|\partial_\theta\log\rho|^2d\theta
=
\int_{S^1}\tan^2\alpha\,d\theta
\]

を定理化する。

### 2.2 接多角形の完全等式

\[
|P|-\pi r^2
=
\frac{r^2}{2}(B_P-2\pi)
=
\frac{r^2}{2}
\int_{S^1}\tan^2\alpha\,d\theta
\]

を、頂点方向における正則性を含めて厳密に記述する。

### 2.3 正 n 角形系列

\[
D_n
:=
n\tan\frac{\pi}{n}-\pi
\]

を4-π系列とし、

\[
D_4=4-\pi,
\qquad
D_n\sim\frac{\pi^3}{3n^2}
\]

を円への収束率として解釈する。

### 2.4 等号・剛性問題

どの図形クラスで

\[
\text{面積欠損}
=
\text{無重み角エネルギー}
\]

が成立するかを分類する。

接多角形以外で同型の完全等式が成立するための必要十分条件を求める。

## 3. 第二段階：変分・安定性

### 3.1 エネルギーの最小化

固定した内接円半径、辺数、周長または対称群の下で

\[
\int_{S^1}|\partial_\theta\log\rho|^2d\theta
\]

を最小化・最大化する図形を求める。

### 3.2 円への距離

角エネルギーが

\[
\rho-r,
\qquad
\log(\rho/r),
\qquad
\text{Hausdorff 距離},
\qquad
\text{Fraenkel 型非対称度}
\]

をどの程度制御するかを調べる。

### 3.3 頂点集中

多角形では角エネルギーは各辺の角域に分布し、法線は頂点で不連続となる。辺数を増やす極限で、エネルギー密度がどのように円へ収束するかを解析する。

## 4. 第三段階：極双対との接続

動径関数 \(\rho_K\) と極体の支持関数 \(h_{K^\circ}\) は

\[
\rho_K(u)=\frac1{h_{K^\circ}(u)}
\]

で結ばれる。したがって、

\[
\partial_\theta\log\rho_K
=-\partial_\theta\log h_{K^\circ}
\]

となる。

これにより4-πエネルギーを、元の図形の動径変化と極図形の支持関数変化の双方として表す。

研究課題：

- 極双対で保存されるエネルギーの条件
- 接多角形と極多角形の角度データ対応
- 面積欠損と極面積欠損の関係
- Mahler 積および Santaló 型量との関係

## 5. 第四段階：高次元化

\(K\subset\mathbb R^d\) を原点について星形とし、動径関数を \(\rho(u)\) とする。形式的には

\[
\frac{dS}{x\cdot n}
=
\rho^{d-2}
\left(1+|\nabla_{S^{d-1}}\log\rho|^2\right)d\omega
\]

となる。

したがって、

\[
\int_{\partial K}\frac{dS}{x\cdot n}
=
\int_{S^{d-1}}\rho^{d-2}d\omega
+
\int_{S^{d-1}}
\rho^{d-2}|\nabla_S\log\rho|^2d\omega.
\]

二次元では \(\rho^{d-2}=1\) となり、基準項が常に \(2\pi\) となる。この無重み化が4-π恒等式を可能にする二次元特有の臨界構造である。

研究課題：

- 内接球をもつ多面体での体積欠損公式
- 三次元で現れる \(\rho\)-重みの幾何学的意味
- 球面 Dirichlet エネルギーとの関係
- cone-volume measure による自然な重み替え

## 6. 幾何双対位相との接続

4-π研究では主に

\[
\tan^2\alpha
\]

を積分する。一方、現在の幾何双対位相では、三次元凸体の基点依存角 \(\alpha_{K,p}\) に対して

\[
E_K(p)
=
\int_{\partial K}\alpha_{K,p}^2\,d\mu_{K,p}
\]

を扱う。

両者の差は、

- \(\tan^2\alpha\) と \(\alpha^2\)
- 無重み角度積分と cone-volume 重み
- 固定原点と可動基点
- 二次元境界曲線と三次元境界面

にある。

今後、これらを結ぶ補間汎関数を構成し、4-π恒等式を現在の幾何双対位相の二次元境界定理として位置づける。
